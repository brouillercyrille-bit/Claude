# Point équipe hebdo

Une seule slide montrée à l'équipe à chaque réunion commerciale du lundi, sans nom de commercial :

1. **Partenaires recrutés à date** : total, recrutés cette semaine, écart vs le lundi précédent, objectif.
2. **Projets en cours** : projets clients finaux ouverts, par phase (Projet détecté / Deal en cours), écart vs le lundi précédent.
3. **Clean data** : nombre de fiches HubSpot à corriger (closings dépassés, deals sans montant, intérêt non renseigné, doublons probables).

Deck en ligne (artifact Slides) : https://claude.ai/artifact/G2DwaW3iV9KUgyU43GaZx8 — modèle dans `modele/`.
Chaque lundi : archiver les données reçues dans `semaines/<AAAA-Snn>/`, remplir la slide et republier le même lien.
